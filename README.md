# Student Management System

## Developed By

Samiksha Chougule

## Project Description

The Student Management System is a console-based application developed in C++. The project helps manage student records efficiently using file handling. It allows users to add, display, search, update, and delete student information through a menu-driven interface.

## Features

* Add Student Records
* Display All Student Records
* Search Student by Roll Number
* Update Student Details
* Delete Student Records
* Persistent Data Storage using File Handling
* User-Friendly Menu Interface

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Vectors
* Functions

## File Structure

StudentManagementSystem/

├── student_management.cpp

## How to Run

1. Compile the program:
   g++ student_management.cpp -o sms

2. Run the program:
   ./sms

This project demonstrates how C++ can be used to create a simple and efficient student record management system with persistent data storage.
